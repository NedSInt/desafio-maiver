Agora quero que você atue como um Product Designer Senior + Frontend Engineer especializado em sistemas SaaS internos modernos.

Sua missão é melhorar significativamente a UI, UX e consistência visual do projeto “Central de Onboarding Maiver”.

IMPORTANTE:
O objetivo NÃO é criar uma interface exagerada ou visualmente artística.

O objetivo é:
- parecer um sistema operacional moderno
- transmitir clareza
- melhorar escaneabilidade
- melhorar produtividade do usuário
- melhorar organização visual
- melhorar experiência de uso
- transmitir sensação de produto profissional

==================================================
OBJETIVOS DE UX
==================================================

Quero uma experiência:
- limpa
- rápida
- moderna
- escaneável
- intuitiva

O usuário deve:
- entender rapidamente o status dos onboardings
- identificar atrasos facilmente
- navegar sem esforço
- visualizar progresso rapidamente
- executar ações com poucos cliques

==================================================

- cards de métricas
- progresso visual forte
- filtros organizados
- espaçamento consistente
- layout moderno

2. Melhor visualização do onboarding
- checklist elegante
- etapas em cards
- badges de status
- indicadores visuais claros
- animações leves e discretas

3. Melhorias nos formulários
- labels consistentes

==================================================

- minimalismo moderno
- consistência visual

- grid organizado
- boa tipografia

- sombras exageradas
- componentes gigantes

- componentes base
- variantes
- estados
- padrões de layout
